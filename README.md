# 百年足跡｜線上尋根之旅

真耶穌教會臺灣傳教100周年的獨立360度導覽網站。

## 線上參觀

GitHub Pages：https://philemon86.github.io/tjc100tour/

手機可滑動全景及雙指縮放；電腦可拖曳、滾輪縮放或使用方向鍵。全景占滿主要畫面，下方只保留上一站、站次、下一站與聆聽按鈕。縮圖集中在「導覽路線」，展區介紹與完整播放器從「展區與語音」打開。

## 內容

- 七樓14張360全景，整理為10個主停留點及4組另一視角。
- 文宣處7段、宣道處1段語音，支援播放、暫停、進度及倍速。第一次進入文宣處詢問是否聆聽，可勾選本次參觀再次走入文宣處時自動播放。同區換站不中斷，離開時暫停；文宣處內依原檔順序接續播放，不臆測各段與特定展品的對應。
- 文宣大事記、聖靈月刊與刊物掛軸共9張閱讀圖片；每個實物上的閱讀點直接開啟對應的完整JPG原稿，不需再選圖片。手機與桌面使用相同原稿，圖片解碼完成後才顯示，避免舊圖配上新標題。
- 百年歷程及手機／桌面響應式版面。

全景恢復4096×2048的JPEG；手機也使用相同畫質。開始參觀前先下載14張全景、9張完整展板與10張路線縮圖，共33張、40,305,086 bytes（約40.3MB）。下載完成且首站渲染完成後才開放導覽；換站、另開展板以已下載的Blob URL讀取，失敗重試保留已完成的檔案。音檔仍按播放才下載。

入場年代動畫獨立於下載速度：時間線在18秒等速前進，每1.8秒呈現一組年代附近的教會建立年份與名稱，最後停留2秒。它是年代導覽而非下載百分比，不顯示月份與日期。動畫結束、全部圖片下載完成且首站渲染完成，三者具備後才開放展廳；網路慢時繼續等候。真實下載張數保留給輔助閱讀。`church-history.json`保留持有人提供的290間教會名稱、日期與年份，沒有地址與經緯度。

下載時僅保留壓縮檔案，不同時解碼所有照片。手機最多保留2張解碼全景、桌面3張，閱讀圖另有2張快取；閒置時準備相鄰視角。換站保留上一站的實際視角，以canvas複製完成柔和淡出，避免編碼PNG；載入完成才更新場景文字。離開頁面時釋放Blob URL，瀏覽器返回快取保留的頁面不提前釋放。

導覽以霧藍綠、奶油白為主色，百年歷程以陶土紅、暖琥珀增加溫暖層次。配色、字體與留白服務於實景閱讀，沒有新增浮動裝飾或自動動畫。

實景素材涵蓋七樓入口、文宣、教牧、聖樂及神學院展區。宣道處位於四樓，目前提供獨立語音，沒有四樓全景。文宣語音依原檔標記1–7，待補齊精確展品對照。

## 維護

本網站不需建置。GitHub Pages從main分支的根目錄發布，`.nojekyll`避免額外Jekyll處理。

- `data.json`：場景、路線、移動點角度、語音、展板及年代。
- `app.js`：全景與互動。
- `image-cache.js`：圖片預解碼、共用請求與有限快取。
- `asset-preloader.js`：整組圖片預下載、真實進度、重試與Blob URL。
- `church-history.json`：持有人提供的教會建立年代。
- `style.css`：版面與配色。
- `assets/`：網頁用照片、語音及展板。
- `vendor/`：Pannellum 2.5.6及其MIT授權。

全景元件的兩項局部效能調整記錄於`vendor/PERFORMANCE-NOTES.md`，保留原MIT授權。

照片、語音及展板由網站持有人提供。請勿將網站程式的使用等同於取得展覽素材的再利用授權。Pannellum授權請參閱`vendor/PANNELLUM-LICENSE.txt`。
