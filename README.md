# 百年足跡｜線上尋根之旅

真耶穌教會臺灣傳教100周年的獨立360度導覽網站。

## 線上參觀

GitHub Pages：https://philemon86.github.io/tjc100tour/

手機可滑動全景及雙指縮放；電腦可拖曳、滾輪縮放或使用方向鍵。點擊全景移動點、導覽路線或縮圖前往其他展區。

## 內容

- 七樓14張360全景，整理為10個主停留點及4組另一視角。
- 文宣處7段、宣道處1段語音，支援播放、暫停、進度及倍速。
- 文宣大事記、聖靈月刊與刊物掛軸共9張閱讀圖片；每個實物上的閱讀點直接開啟自己的原圖，不需再選圖片。原圖載入與解碼完成後才顯示，避免舊圖配上新標題。
- 百年歷程及手機／桌面響應式版面。

全景採用 WebP：桌面4096×2048、手機2048×1024。換站時保留上一站的實際全景視角，下一站準備完成後才切換。語音按播放才下載；當站載入完成後預取下一站，省流量或2G連線停用預取。

導覽以霧藍綠、奶油白為主色，百年歷程以陶土紅、暖琥珀增加溫暖層次。配色、字體與留白服務於實景閱讀，沒有新增浮動裝飾或自動動畫。

實景素材涵蓋七樓入口、文宣、教牧、聖樂及神學院展區。宣道處位於四樓，目前提供獨立語音，沒有四樓全景。文宣語音依原檔標記1–7，待補齊精確展品對照。

## 維護

本網站不需建置。GitHub Pages從main分支的根目錄發布，`.nojekyll`避免額外Jekyll處理。

- `data.json`：場景、路線、移動點角度、語音、展板及年代。
- `app.js`：全景與互動。
- `style.css`：版面與配色。
- `assets/`：網頁用照片、語音及展板。
- `vendor/`：Pannellum 2.5.6及其MIT授權。

照片、語音及展板由網站持有人提供。請勿將網站程式的使用等同於取得展覽素材的再利用授權。Pannellum授權請參閱`vendor/PANNELLUM-LICENSE.txt`。
